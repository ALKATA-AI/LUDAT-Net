Overview

Monaural speech enhancement aims to recover clean speech from recordings contaminated by background noise. LUDAT-Net is a deep learning approach developed for this task, with an emphasis on speech reconstruction and efficient model design.

This demo provides audio examples for qualitative comparison. Each example includes the noisy input, the clean reference, and the enhanced output produced by LUDAT-Net.
