# Audio Samples

This directory contains the WAV files used by the LUDAT-Net demo page.

For each utterance, provide the noisy input, clean reference, and enhanced output using the filenames listed below.

## Required files

- `sample1_noisy.wav`
- `sample1_clean.wav`
- `sample1_ludat.wav`
- `sample2_noisy.wav`
- `sample2_clean.wav`
- `sample2_ludat.wav`
- `sample3_noisy.wav`
- `sample3_clean.wav`
- `sample3_ludat.wav`

Use the same utterance for all three recordings in each sample group. Keep the audio format consistent, preferably mono WAV at 16 kHz.

The enhanced files should be generated by the trained LUDAT-Net model. Do not use unrelated recordings as substitutes.
