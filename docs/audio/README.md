# Audio Samples

This directory contains the WAV files used in the online demo of LUDAT-Net for monaural speech enhancement.

**Online Demo:** [Listen to the LUDAT-Net Audio Demo](https://alkata-ai.github.io/LUDAT-Net/)

The demo presents an audio-based ablation study comparing two configurations of the LUE hierarchy: **1LU** and **2LU**. For each utterance, it provides the noisy input, clean reference, and enhanced speech generated by both configurations.

## Included Utterances

The demo includes the following six utterances from the VoiceBank+DEMAND dataset:

- `p232_010`
- `p232_023`
- `p232_052`
- `p232_415`
- `p257_009`
- `p257_130`

## Directory Structure

Relative to the repository root, the audio files are organized as follows:

```text
LUDAT-Net/
└── Samples/
    ├── Noisy/
    │   ├── p232_010.wav
    │   ├── p232_023.wav
    │   └── ...
    ├── Clean/
    │   ├── p232_010.wav
    │   ├── p232_023.wav
    │   └── ...
    ├── LUDAT-Net (1LU)/
    │   ├── p232_010.wav
    │   ├── p232_023.wav
    │   └── ...
    └── LUDAT-Net (2LU)/
        ├── p232_010.wav
        ├── p232_023.wav
        └── ...
```

Each subdirectory contains the corresponding WAV files for all six utterances.

## Audio Format

The recordings are provided in WAV format. For each utterance, the noisy input, clean reference, and enhanced recordings correspond to the same speech sample, enabling a consistent listening comparison between the two configurations.
